# QA-01: dựng DX-Lab từ mã nguồn theo README

Chạy đúng các bước của mục "Cài đặt & Khởi động" trong `README.md`: `git clone` → `scripts/up.sh` →
`scripts/download-models.sh` → `scripts/seed.sh` → `scripts/demo-e2e.sh`.

## Môi trường và giới hạn

| Mục | Giá trị |
|---|---|
| Máy | macOS 27.2, Apple Silicon (arm64), Docker Engine 29.8.2, Docker Compose 5.5.0 |
| Người chạy | mentor của đội, ngày 01/11/2026 |
| Mã nguồn | `git clone https://github.com/HaUI-NPC/dx-lab.git` vào thư mục mới trong `/tmp` |

**Đây không phải một máy khác.** Lần chạy dùng máy của mentor. Để gần với máy sạch nhất có thể, trước lần 2 đã:

- gỡ toàn bộ container và volume của project `dxlab` (`docker compose down -v`);
- xóa image `dxlab-core`, `dxlab-portal` và ba image gốc PostgreSQL, Keycloak, APISIX;
- xóa toàn bộ build cache (`docker builder prune -af`).

Log lần 2 cho thấy cả ba image gốc được kéo lại (`Pulled`). Một vài lớp vẫn báo `CACHED` vì dùng chung bước giữa hai
image `core` và `portal` trong cùng lần build. Bộ cài `uv`, Python và cache tải gói trên máy chủ không ảnh hưởng vì
build chạy trong container.
